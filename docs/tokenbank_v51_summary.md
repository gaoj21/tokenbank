# TokenBank v5.1：固定 token 预算下的 agent 推理治理

> **v5.3 定稿**（2026-08-30，含 Z1b/Z1c 归因重做）：经两轮加固（v5.2/v5.3）修订。
> 全部 SR 数字以 **Unc+Fmt（格式对齐基线）** 为正式对照，带 95% CI 与配对显著性。
> 判决全过程见 `experiment_findings_v5.md` §8.3–8.4c。
>
> ⚠️ **本版最重要的修订**：MATH +8.0pp 的机制归因重做了两轮。此前"M1 防过度修订
> 贡献 75%"作废（错基线审计 + 一个测不到 M1 的消融）；补上 Ab6 隔离臂后，增益在
> 固定管线下可加法分解——**M3 上下文经济学 +5.2pp（p=0.005，唯一显著项）**、
> M1 +2.2pp（方向性）、M2 级联 +0.4pp 但省 42% token。详见 §8.4b–8.4c。
>
> 模型：Qwen3.6-27B-FP8（vLLM），temp=0，seed=42；跨模型：Gemma-4-31B-it（llama.cpp QAT q4_0）。
> 数据集均为 test split：GAIA(122) / MATH(400) / FRAMES(660) / MuSiQue(1934)。

## 1. 问题设定与基线

多步 agent（Plan→Execute→Review，≤5 轮）在**固定 token 预算**下跑批任务。
正式基线：**Unc+Fmt** = 朴素固定管线（无早停、无级联、无上下文压缩，
executor max_tokens=2048、有代码工具）+ `ANSWER: xxx` 输出指令。
（Unc = 连格式指令都没有的更弱基线，仅作附录参考——v5.2/v5.3 证明
格式指令本身就是最大的单块"增益"，不以它为对照的比较有抽取优势的混淆。）

## 2. 方法与各机制的最终定位（全部经消融实测）

| 机制 | 内容 | 实测定位 |
|---|---|---|
| M3.4 答案格式 | `ANSWER: xxx` 单行输出 | **评测协议对齐**。GAIA/FRAMES/MuSiQue 的全部 SR 增益、MATH 增益的 57% 来自它（Unc+Fmt 对照臂实测）。不算治理功劳，但缺它对朴素基线不公平 |
| M1 收敛早停 | 答案两轮等价/reviewer 接受 + logprob>τ_conf → 停；熵高 → 继续 | **防真·过度修订**。固定管线下（Ab3 vs Ab6）把 strict 中途改错 25→17、条件翻转率 8.4%→5.7%；SR +2.2pp 但 **p=0.175 不显著**，只能作方向性陈述。与 M2 的 L0 降档**互为冗余替代**（两者治同一个病），所以级联开着时单独拿掉它只掉 1pp |
| M2 语言化级联 | L0 直答 → L1 带工具 → L2 全管线；升级靠模型自声明 ESCALATE（优先于 logprob 门控 θ0/θ1） | **防反噬 + 计算型 token 效率 + MATH 上的分流增益**。纯 logprob 路由把计算题按在 L0 导致反噬（Qwen MATH 49.2%<52.8%；Gemma 36.0%<39.0%）；语言化判据修复后，MATH 上 77% 的题停 L0，**同分省 42% token**（3,283 vs Ab3 的 5,648）。**SR 上仅 +0.4pp**（vs 正确对照臂 Ab3）——它不是增益来源，是同增益下的省钱开关：靠"根本不跑管线"规避多轮劣化，与 M3+M1 的"把管线修好"互替 |
| M3.1/3.2/3.3 上下文经济学 | reviewer JSON、工具笔记、plan 裁剪 | **MATH 上唯一显著的 SR 贡献项**：固定管线下 +5.2pp，p=0.0046（Ab6 vs Unc+Fmt）。机制是省 token → 任务不再耗尽预算 → 消灭劣质收尾（budget-finalize 9→0）。⚠️ 该数含 `m5_strategy=hybrid` 混淆，未拆分。MuSiQue 上的 −M3ctx null 只在级联下、且只对该集成立 |
| M4 池化（可选） | two-pass 探针 + 边际价值排序 | 计算型同分省 8–12% token；检索型因 draft 锚定提前收敛而亏损。默认关 |

> **归因的关键前提（v5.3 Z1b+Z1c，`experiment_findings_v5.md` §8.4b–8.4c）**：此前"四个单机制消融全部 null"是**级联造成的假象**——语言化路由把 305~310/400 道 MATH 题停在 L0 单轮直答，任何"改善管线"的机制都只剩 ~23% 的题可作用。**关掉级联（强制全 L2）后增益即可加法分解**：Unc+Fmt 63.2% →(+M3ctx+M5) 68.5% →(+M1) 70.8% →(+M2) 71.2%，即 5.2+2.2+0.4 ≈ 8.0pp。
>
> 由此得到本工作真正的核心命题：**朴素多轮管线在计算题上有净损害**（把已答对的改坏、预算耗尽时劣质收尾），而**"修好管线"（M3+M1）与"不跑管线"（M2 降档）治的是同一个病**——两条路径互替，后者同等 SR 下省 42% token。

删除的机制（v5 已证无效/有害）：跨 agent 借贷、per-role 配额、predictive 估计、stall 检测、best-of-n。

## 4. 边界（诚实声明）

- **GAIA/FRAMES 与基线同一条 Pareto 前沿**：8k/16k/24k 三个预算点两线重合
  （8k 处 FRAMES 的 Unc+Fmt 甚至更省 token）——这两集上 token 效率 claim 不成立
- **GAIA 上预算帽对朴素管线不绑定**：24k 与 16k 的 Unc+Fmt 正确集差异恰等于
  运行噪声（对称差 6.6% = 翻转率），说明该集上预算治理没有作用对象
- **运行噪声**：vLLM 连续批处理 temp=0 下逐题翻转率 ~6%（GAIA 6.6%、MATH 5.5%
  两集实测）；GAIA 上 <3.3pp 的差值不值得解释。MATH 的 +8pp 是漂移 SD 的 6 倍
- 单 seed、temp=0（以配对检验 + 双数据集翻转率实测替代多种子）
- **M3ctx 与 M5 未拆分**：+5.2pp 是 M3.1/3.2/3.3 与 `m5_strategy=hybrid` 的合计
  （`V5-Unc-Fmt` 不带 m5 键）。再去掉 M5 一臂即可拆开（400 题·次未做）
- **M1 的 SR 效应不显著**：+2.2pp，配对 CI [−0.5, +5.2]，p=0.175。可说"减少过度
  修订（strict 25→17）且方向为正"，不可说"带来 +2.2pp"
- **跨模型证据只覆盖失效模式，不覆盖 SR 增益**：Gemma 的 +25.8pp 是对 **Unc**
  （无格式）测的，正是 C1/E1 在 Qwen 上证明会虚高 57% 的那种比较——**不应作为
  方法 SR 增益的跨模型证据引用**。不受影响的是反噬-修复 claim（Gemma A0 36.0%
  < Unc 39.0% 属 v5 臂内比较，与格式无关）。补 Gemma×Unc+Fmt×MATH 需 400 题·次

## 5. 一句话结论

**在格式对齐的公平基线上：方法的 SR 增益只剩计算型任务一处（MATH +8.0pp，p≈2e-8）。
该增益在固定管线下可加法分解——上下文经济学 +5.2pp（p=0.005，唯一显著项）、
防过度修订 +2.2pp（方向性）、级联 +0.4pp 但省 42% token；语言化级联防反噬经
双模型验证；其余数据集上与基线同分但显著省 token（MuSiQue −20%）；知识问答型
任务上方法到达边界——与基线同前沿。**

核心命题两条，都有对照臂支撑：

1. **朴素多轮 agent 管线在计算题上有净损害**——把已答对的答案改坏、并在预算耗尽时
   给出劣质收尾（Unc+Fmt 63.2% vs 按需降档的 71.2%）
2. **这个损害有两条互替的修法**——把管线修好（M3+M1，+7.5pp）或干脆不跑管线
   （M2 降档，同等 SR 省 42% token）。这解释了为什么单独拿掉任一机制都近乎 null

写作时按这两条组织，不要写成"预算治理机制带来了增益"。
