## 1. Phase Z：零 GPU（先做，可能直接填掉空洞 B）

### Z1 — 过度修订审计 【B 的零成本证伪，最高优先】

**假说**：Unc 是"所有题跑满 ≤5 轮、无早停"，MATH 上无归属的 ~12pp 来自**模型把已经答对的答案改错**；M1 的价值不是"省 token"，而是**在正确答案上收火**。

做法：从 Unc 的 traces 逐题扫 `rounds[].is_correct`，统计：

1. 存在某轮 `is_correct=True` 但**最终答案错**的任务数（correct→wrong 翻转）
2. 该翻转数占各数据集 SR 差值的比例
3. 反向对照：V5.1-NoPool traces 里同一指标（M1 应把它压到接近 0）
4. 翻转发生的轮次分布

**判读**（目标量级）：MATH 未归属 ~12pp ≈ **48 题**；MuSiQue ~2.6pp ≈ **50 题**。

- 翻转数接近该量级 → **机制识别完成，E2 可以不跑**。M1 的定位从"token 节省"改写为"防过度修订"，这比"上下文经济学提升质量"更具体也更有意思
- 翻转数远小于该量级 → 增益归 M3，**E2 必须跑**

> 这是本轮性价比最高的一项：一个 zero-GPU 的 trace 扫描，有可能省掉 E2 的 3,868 题·次。

### Z2 — 补齐正式基线的统计 【修正呈现倒置】

当前主表对 **Unc**（已判定为错误的对照）给了 CI + McNemar 全套，对 **Unc+Fmt**（§1 自己定义的 GAIA/FRAMES 正式基线）一个都没有。

- Unc+Fmt 列补 95% CI
- 补 **NoPool vs Unc+Fmt** 的 McNemar p 与配对 Δ CI（GAIA/FRAMES × 24k/16k 共 4 格）
- Unc 列降到附录

### Z3 — Pareto 图 【C 的呈现】

每数据集一张 SR vs 实际平均 token 散点，**同一臂的多个预算点连成曲线**，标出 NoPool / Unc+Fmt / Unc / Unified。GAIA/FRAMES 的判决直接看两条曲线是否重合。

### Z4 — GAIA 的 Unc+Fmt 同分核查

24k 与 16k 的 Unc+Fmt 都是 **19.7%**（24/122）。token 花费不同（13,264 vs 10,986），说明是两次独立运行，但需核查：

- 两次的**逐题正确集合**是否相同
- 若几乎相同 → 说明 **GAIA 上预算帽对朴素管线根本不绑定**，这本身是个该写进正文的发现（也直接解释了空洞 C）
- 若差异明显而 SR 恰好相等 → 巧合，注明即可

### Z5 — 双噪声源合并口径

当前 McNemar 只计入抽样噪声，未计入运行不确定性。按 √(f/n)（f=6.6%）给出运行漂移 SD 并与抽样噪声合并：

| 数据集 | n | 运行漂移 SD | 关键差值 | 倍数 |
|---|---|---|---|---|
| GAIA | 122 | 2.3pp（实测 3.3pp） | ±0.8pp | 0.3× |
| MATH | 400 | 1.3pp | +18.5pp | 14× |
| FRAMES | 660 | 1.0pp | +0.4pp（vs Unc+Fmt） | 0.4× |
| MuSiQue | 1934 | 0.6pp | +2.6pp | 4.5× |

合并后结论不变（MATH/MuSiQue 稳，GAIA/FRAMES 为零），但口径干净。**顺带在 MATH 上补一次同配置重跑测翻转率**（见 E4），避免 6.6% 是 GAIA 独有。

### Z6 — 文字修订清单（与实验并行）

| 位置 | 现状 | 改法 |
|---|---|---|
| §3 claim 表 "跨模型（Gemma +25.8pp）" vs §4 "Gemma 上尚未复测" | **自相矛盾** | 二选一；并写明 +25.8pp 的基准是 Gemma-Unc 还是 v5 logprob 级联(36.0%) |
| §3 "MuSiQue 格式假说上界为 0" | 断言，无推导 | 正文补一句推导（若依据是"Unc 抽取失败题的 f1 全为 0"，写出来即可，论证很干净） |
| §2 "M3——SR 增益的主要来源"、"M1——检索型 token 节省的主因" | 无消融支撑的因果归因 | 改中性描述，等 Z1/E2 |

## 2. Phase E：实验（按决定性排序）

### E1 — MATH × Unc+Fmt 【空洞 A，必跑】

- 配置：Unc + 仅 `ANSWER:` 输出指令，其余不变
- 数据集/预算：MATH test(400) × 24k、16k
- 成本：**800 题·次**（最便宜的一项）

**判读**：

- Unc+Fmt 仍 ≪ NoPool（预期在 55~60% 区间）→ 头条 claim 完全站住，"≥64%" 换成实测数字
- Unc+Fmt 大幅上跳（>65%）→ MATH 的增益同样是格式主导，**整篇的结论要重写**，剩下只有 MuSiQue

> 风险不对称：这一臂是全文最大战果的唯一未做对照。不跑就投稿，等于把最大的风险留给审稿人去发现。

### E2 — MuSiQue 归因消融 【空洞 B，**受 Z1 结果 gate**】

- 配置：`V5.1 −M1`、`V5.1 −M3`（M3 去掉格式项后的部分：M3.1 reviewer JSON + M3.2 工具笔记 + M3.3 plan 裁剪）
- 数据集/预算：MuSiQue test(1934) × 24k
- 成本：**3,868 题·次**（本轮最贵）

**为什么必须是 MuSiQue**：它是唯一还剩真实待解释 SR 增益的数据集（GAIA/FRAMES 已归格式，MATH 由 E1 处理），也是唯一从未做过消融的。dev(483) 的 Δ 标准误约 2.7pp，分辨不出 2.6pp 的效应，**只能用 test**。

**Gate**：若 Z1 已把 MATH+MuSiQue 的增益归因到"防过度修订"，则本项缩减为只跑 `−M1`（1,934 题·次，减半）。

### E3 — 第三个预算点 【空洞 C】

- 配置：`V5.1-NoPool` 与 `Unc+Fmt` × **8k**
- 数据集：GAIA(122) + FRAMES(660)
- 成本：**1,564 题·次**

两个点连不成曲线，三个点才能判断两条前沿是否真的重合。若 8k 处 NoPool 明显高于 Unc+Fmt，"同前沿"结论翻案，token 效率 claim 恢复。

### E4 — MATH 翻转率（并入 Z5）

- `V5.1-NoPool × MATH(400) × 24k` 同配置重跑一次，测逐题翻转率
- 成本：400 题·次

## 3. 决策门

| 门 | 依据 | 走向 |
|---|---|---|
| **G-A** | E1 | Unc+Fmt ≪ NoPool → 头条成立，"≥64%/≤36%" 替换为实测；否则整篇结论收缩到 MuSiQue |
| **G-B** | Z1 →（必要时）E2 | 翻转数接近 12pp 量级 → M1 定位改为"防过度修订"，E2 缩减；否则增益归 M3，E2 全跑 |
| **G-C** | Z3 + Z4 + E3 | 三点前沿重合 → GAIA/FRAMES 写"同前沿、无增益"；分离 → 恢复 token 效率 claim |

### 最终叙事的三种形状

1. **A 通过 + B 归 M1**（最好）：*"固定预算下，防止过度修订 + 上下文卫生带来 MATH +18pp / MuSiQue +3pp；语言化升级判据是让级联不在计算型任务上反噬的必要条件；在知识问答型任务上，方法与格式对齐的朴素基线同前沿。"* —— 机制清楚、边界诚实、有跨模型证据
2. **A 通过 + B 归 M3**：同上，主角换成上下文经济学，需 E2 的完整消融支撑
3. **A 不通过**：战果收缩为 MuSiQue 单点 + 全线 token 效率，**方法仍有价值但不足以支撑当前的叙事强度**，应改投更小的场子或补新数据集

## 4. 执行顺序与成本

```
第 1 步（0 卡，1 天）：Z1 → Z2 Z3 Z4 Z5 并行 → Z6 文字修订
                       ↓ 读 G-B 的前半
第 2 步（卡）：E1（800 题·次）        ← G-A，优先级最高
              E3（1,564 题·次）       ← G-C，可与 E1 排队
              E4（400 题·次）
                       ↓
第 3 步（卡，仅在 Z1 未定案时）：E2（1,934 或 3,868 题·次）
                       ↓
第 4 步：主表定稿 + 文档改写 → 停止实验
```

总成本上界 **6,632 题·次**；若 Z1 定案则降到 **4,698**；若 Z1 定案且 G-C 早判，可再降。

## 5. 出表规范（在 v5.2 基础上增补）

1. 主表基线列 = **Unc+Fmt**（GAIA/FRAMES/MATH），Unc 移入附录
2. 每格并列：SR [95% CI] / 实际平均 token / **vs 正式基线的 McNemar p**

5. 所有因果归因句必须能指到一个消融编号；指不到的改成中性描述

## 6. 不做的事

- **不再新增机制**，v5.3 只做归因与边界
- **不做多种子**；用配对检验 + 翻转率下界替代（现已两数据集实测）
- **不再动 GAIA 的 SR claim**：n=122 + 6.6% 翻转率，该集上任何 SR 差值都不可解释，只用于方向性与 token 讨论
- **不跑 Gemma 的第二轮**：现有跨模型证据足以支撑"失效模式跨模型"，Z6 把措辞改准即可；除非 G-A 不通过需要换叙事
- **E2 在 Z1 出结果前不排队**——它是本轮唯一的大额支出，不能盲跑
